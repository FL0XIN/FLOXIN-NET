
## NETTURBO

`NETTURBO scan` prueba ocho puertos HTTPS y guarda el historial en SQLite. Usa `best`, `monitor`, `apply --port 8443`, `status`, `history` y `report`. Solo guarda una recomendación para clientes compatibles; no redirige de forma transparente todo el tráfico del sistema.
