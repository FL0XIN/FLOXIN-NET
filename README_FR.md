
## NETTURBO

`NETTURBO scan` teste huit ports HTTPS et conserve l’historique dans SQLite. Utilisez `best`, `monitor`, `apply --port 8443`, `status`, `history` et `report`. L’outil enregistre une recommandation pour les clients compatibles ; il ne redirige pas automatiquement tout le trafic du système.
