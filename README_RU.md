
## NETTURBO

`NETTURBO scan` проверяет восемь HTTPS-портов и сохраняет историю в SQLite. Используйте `best`, `monitor`, `apply --port 8443`, `status`, `history` и `report`. Инструмент сохраняет рекомендацию для совместимых клиентов, но не перенаправляет прозрачно весь системный трафик.
