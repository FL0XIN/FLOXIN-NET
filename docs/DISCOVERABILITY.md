# Discoverability

FLOXIN NET is described with stable, accurate search terms in the root README and GitHub repository metadata:

- local DNS
- DNS ad blocker
- DNS cache
- network diagnostics
- latency and jitter
- packet loss
- MTU and TCP recommendations
- CDN port measurement
- Android DNS VPN
- privacy tools

The project uses GitHub Actions status badges, localized README files, a license, a citation file, and a security policy. These improve indexing and trust signals, but they do not guarantee search ranking, traffic, or GitHub stars. Stars must come from genuine users; automated or purchased stars are not used.
