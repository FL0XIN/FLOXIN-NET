# Security Policy

## Supported versions

The latest commit on `main` is the supported development version. Older releases may not receive fixes.

## Reporting a vulnerability

Please do not publish exploitable details in a public issue. Open a private GitHub security advisory at:

https://github.com/FL0XIN/FLOXIN-NET/security/advisories/new

Include the affected command or file, reproduction steps, impact, and a safe suggested fix when possible. Do not include passwords, access tokens, private DNS logs, or other sensitive data.

FLOXIN NET is measurement-first software. It does not claim to bypass provider policies, create a VPN, or transparently redirect all system traffic.
